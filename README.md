# 💅 Telegram Mini App для записи на маникюр

Полноценное мини-приложение для Telegram с красивым интерфейсом для записи клиентов на маникюр. Включает админ-панель для управления доступным временем.

## 🚀 Возможности

- ✅ Красивый пошаговый интерфейс для записи клиентов
- ✅ Выбор услуги, мастера, даты и времени
- ✅ Админ-панель для управления доступным временем
- ✅ Все данные сохраняются в базе данных SQLite
- ✅ Интеграция с Telegram Web App API
- ✅ Адаптивный дизайн для мобильных устройств

## 📋 Требования

- Python 3.8+
- Node.js 14+
- Telegram Bot Token

## 🛠️ Установка

### 1. Настройка переменных окружения

**ВАЖНО:** Токен бота хранится в файле `.env`, который не попадает в Git репозиторий.

1. Создайте файл `.env` в корне проекта:
```bash
# Windows
copy .env.example .env

# Linux/Mac
cp .env.example .env
```

2. Откройте файл `.env` и добавьте ваш токен бота:
```
BOT_TOKEN=ваш_токен_здесь
```

Получить токен можно у [@BotFather](https://t.me/BotFather) в Telegram.

### 2. Установка Python зависимостей

```bash
pip install -r requirements.txt
```

### 3. Установка Node.js зависимостей

```bash
cd webapp/client
npm install
```

### 4. Настройка

1. Убедитесь, что создали файл `.env` с токеном (см. шаг 1)
2. Обновите URL в `bot.py` на адрес вашего хостинга (или используйте ngrok для локальной разработки)

## 🚀 Запуск

### 1. Запуск API сервера

```bash
python api.py
```

API будет доступен на `http://localhost:5000`

### 2. Запуск React приложения (для разработки)

```bash
cd webapp/client
npm start
```

### 3. Сборка для продакшена

```bash
cd webapp/client
npm run build
```

### 4. Запуск Telegram бота

```bash
python bot.py
```

## 📱 Использование

### Для клиентов:

1. Откройте бота в Telegram
2. Нажмите кнопку "💅 Записаться на маникюр"
3. Следуйте пошаговым инструкциям:
   - Выберите услугу
   - Выберите мастера
   - Выберите дату
   - Выберите время
   - Подтвердите запись

### Для администраторов:

1. Используйте команду `/admin` в боте для получения прав администратора
2. В меню бота появится кнопка "⚙️ Админ-панель"
3. В админ-панели вы можете:
   - Добавлять доступное время для записи
   - Удалять слоты
   - Просматривать все доступные слоты

## 🗄️ Структура базы данных

- `bookings` - записи клиентов
- `masters` - мастера
- `services` - услуги
- `available_slots` - доступные временные слоты
- `admins` - администраторы

## 🔧 Настройка для продакшена

1. Замените `CLIENT_WEBAPP_URL` и `ADMIN_PANEL_URL` в `bot.py` на реальные URL
2. Установите переменную окружения `REACT_APP_API_URL` для указания адреса API
3. Настройте CORS в `api.py` для вашего домена
4. Используйте HTTPS для всех URL (обязательно для Telegram Web App)

## 📝 API Endpoints

- `GET /api/services` - получить список услуг
- `GET /api/masters` - получить список мастеров
- `GET /api/slots?date=YYYY-MM-DD&master=name` - получить доступные слоты
- `POST /api/bookings` - создать запись
- `GET /api/admin/slots?user_id=ID` - получить все слоты (только для админов)
- `POST /api/admin/slots` - добавить слот (только для админов)
- `DELETE /api/admin/slots` - удалить слот (только для админов)
- `GET /api/admin/check?user_id=ID` - проверить права администратора

# 🚀 Быстрый старт

## Шаг 1: Установка зависимостей

```bash
# Python зависимости
pip install -r requirements.txt

# Node.js зависимости
cd webapp/client
npm install
```

## Шаг 2: Настройка бота

1. Откройте `bot.py`
2. Замените `TOKEN` на токен вашего Telegram бота (получите у @BotFather)
3. Обновите `CLIENT_WEBAPP_URL` и `ADMIN_PANEL_URL` на адреса вашего хостинга

## Шаг 3: Инициализация базы данных

```bash
python init_db.py
```

Это создаст:
- Таблицы в базе данных
- Начальных мастеров (Анна, Мария, Елена)
- Начальные услуги
- Тестовые временные слоты на 7 дней вперед

## Шаг 4: Запуск

### Терминал 1: API сервер
```bash
python api.py
```

### Терминал 2: Telegram бот
```bash
python bot.py
```

### Терминал 3: React приложение (для разработки)
```bash
cd webapp/client
npm start
```

## Шаг 5: Получение прав администратора

1. Откройте бота в Telegram
2. Отправьте команду `/admin`
3. Теперь в меню появится кнопка "⚙️ Админ-панель"

## Шаг 6: Добавление временных слотов

1. Откройте админ-панель через бота
2. Нажмите "+ Добавить слот"
3. Выберите мастера, дату и время
4. Нажмите "Добавить"

## 📝 Примечания

- Для локальной разработки используйте ngrok для создания HTTPS туннеля:
  ```bash
  ngrok http 3000  # для React приложения
  ngrok http 5000  # для API
  ```

- В продакшене обязательно используйте HTTPS для всех URL
- Настройте переменную окружения `REACT_APP_API_URL` для указания адреса API

## 🐛 Решение проблем

**Проблема:** CORS ошибки
**Решение:** Убедитесь, что API сервер запущен и доступен по указанному адресу

**Проблема:** Бот не отвечает
**Решение:** Проверьте токен бота и убедитесь, что бот запущен

**Проблема:** Нет доступных слотов
**Решение:** Запустите `python init_db.py` или добавьте слоты через админ-панель
